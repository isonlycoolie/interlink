## Usage

Use pagination when a list is too long to show at once and people need to reach a specific page.

## Best practices

- Show the current page clearly; the selected page is marked for assistive technology too.
- Keep `max` at seven or fewer page buttons so the control stays scannable.
- Place pagination below the content it controls.
