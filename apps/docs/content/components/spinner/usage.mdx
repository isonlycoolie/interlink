## Usage

Use a spinner for short waits inside a component or region. For longer work with known progress, use a progress
bar; for loading layouts, use skeletons.

## Best practices

- Add a `delay` so fast operations never flash a spinner.
- Use one spinner per region, not one per item.
- Label the spinner when no nearby text says what is loading.
