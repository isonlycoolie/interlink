## Usage

The prompt input grows with the text up to a limit, then scrolls. Enter sends and Shift+Enter starts a new line.

## Best practices

- Show what the agent will look at as context chips, so people can remove what does not belong.
- Disable send while an answer is being written, and wrap the input in a generative border.
- Write a placeholder that suggests what to ask, not "Type here".
