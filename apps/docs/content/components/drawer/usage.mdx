## Usage

Use a drawer for a task or detail view that benefits from keeping the page in sight, such as editing an item from a
list. For short confirmations, use a modal dialog.

## Best practices

- Choose the narrowest width that fits the content.
- Always include `DrawerCloseButton` so the way out is visible.
- Name the drawer with `label` or a visible title linked through `titleId`.
