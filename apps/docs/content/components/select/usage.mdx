## Usage

Use a select when there are too many options for radio buttons or checkboxes. Turn on `isMulti` for several values, use AsyncSelect for options from a server and CreatableSelect when people can add their own.

## Keyboard

| Key | Action |
| --- | --- |
| Arrow down | Open the menu, then move to the next option |
| Enter | Choose the active option |
| Typing | Filter the options |
| Backspace | Remove the last value of a multi select |
| Escape | Close the menu |
