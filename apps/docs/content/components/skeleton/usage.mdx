---
title: Skeleton usage
description: A skeleton is a placeholder shape shown while content loads.
---

## Usage

Use skeletons when the layout of the loading content is known, so the page does not jump when it arrives. For short
waits inside a component, use a spinner.

## Best practices

- Match the skeleton to the real layout: same widths, heights and spacing.
- Shimmer is gentle and switches off when people ask for reduced motion.
