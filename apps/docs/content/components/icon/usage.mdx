## Usage

Icons help people scan and recognise. They work best next to text, and only alone when their meaning is
unmistakable, such as close or search.

## Accessibility

- Give every icon a `label`. Use an empty label only when nearby text already says the same thing.
- Never rely on an icon's color alone to carry meaning.
