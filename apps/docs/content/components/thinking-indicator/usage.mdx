## Usage

Show the thinking indicator while an agent works on an answer. Say what it is doing when you know, such as
"Searching 24 pages…", so waiting feels shorter and people can tell what the answer will be based on.

## Accessibility

- It is a status region, so screen readers announce the label when it appears.
