## Usage

Use a dynamic table for lists of records people compare, sort and act on.

## Best practices

- Make columns sortable when people look for the highest, lowest or newest.
- Use `rowsPerPage` for long lists, and `emptyView` to explain an empty table and offer an action.
- Give the table a `caption`, or a `label` when the heading is elsewhere.
