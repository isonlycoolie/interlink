## Usage

Buttons start actions that change something on the current page: saving a form, opening a dialog, starting a
process. When the action takes people somewhere else, use a link or a `LinkButton` instead.

## Parts

A button has a label, an optional icon before or after it, and the clickable area. Most buttons do not need an
icon; add one only when its meaning is obvious.

## Use buttons for actions and links for navigation

Buttons change something here; links take people somewhere else. Screen readers announce them differently, so
choosing the wrong one makes the page harder to use.

## Accessibility

### Avoid disabling buttons

<Guidelines topic="button" section="Avoid disabling buttons" />

- Every button needs a visible label or, for icon buttons, a `label` that names the action.
- Loading buttons keep focus and announce that they are busy; do not remove them from the page.
