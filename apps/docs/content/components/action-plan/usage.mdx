## Usage

Show the plan before an agent acts on several things, and keep it on screen while it runs. Done steps fill in, the
current step is marked, and failed steps stand out.

## Best practices

- Start each step with a verb and keep it to one line; put numbers and names in the detail.
- Offer a way to stop while the plan runs.
