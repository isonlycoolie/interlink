## Usage

Avatars help people recognise who did what. Use circles for people and squares for teams, projects and apps.

## Best practices

- Always pass a `name`: it labels the avatar and gives the initials fallback a stable color.
- When the name is shown next to the avatar, set `label=""` so it is not read twice.
- Use presence only where availability matters, such as chat.
