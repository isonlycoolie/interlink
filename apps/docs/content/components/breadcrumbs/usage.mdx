## Usage

Use breadcrumbs on pages that sit inside a hierarchy, so people can see where they are and move up a level.

## Best practices

- Start at the highest useful level and end with the current page.
- Keep item text short; set `truncationWidth` for long names.
- Long trails collapse in the middle; people can expand them with the ellipsis button.
