## Usage

Use an assist button when an action is carried out by AI, such as summarising or drafting. The mark sets it apart
from ordinary actions next to it.

## Best practices

- Name the result, not the technology: "Summarise", not "Use AI".
- Keep one assist button per area; group more actions in its menu with `hasMenu`.
