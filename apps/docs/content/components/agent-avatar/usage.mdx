title: Agent avatar usage
description: The hexagon avatar of an agent, reserved for agents so people always know when one is at work.
---

## Usage

The hexagon belongs to agents only. Wherever an agent shows up (a byline, a list of people, a presence list) its
hexagon tells people that software, not a person, did the work.

## Best practices

- Never put a person in a hexagon, and never put an agent in a circle.
- Give each agent one colour and one glyph and keep them everywhere it appears.
- Use `onBehalfOf` when an agent acts for someone, so the person who asked stays visible.
