---
title: Checkbox usage
description: A checkbox lets people choose any number of options, or turn one option on and off.
---

## Usage

Use checkboxes for independent choices. For a setting that applies immediately, use a toggle. For a choice of
exactly one option, use radio buttons.

## Best practices

- Write labels as positive statements: "Email me updates", not "Don't email me".
- Use the indeterminate state only for a parent whose children are partly selected.
- Group related checkboxes in a `Fieldset` with a legend.
