## Usage

Presence cursors show who else is here and where they are working. People each get their own colour; agents use the
ink pill with their hexagon, so an agent's edits are never mistaken for a person's.

## Best practices

- Keep one colour per person for the whole session.
- Use the first name only; the full name lives in the presence list.
- Use the large size only in marketing pictures.
