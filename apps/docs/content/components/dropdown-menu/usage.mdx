---
title: Dropdown menu usage
description: A dropdown menu is a button that opens a list of actions or options.
---

## Usage

Use a dropdown menu to tuck away related actions, or to let people pick options that apply straight away.

## Best practices

- Group related items and add a title when the groups are not obvious.
- Put destructive actions last, in their own group.
- Use checkbox and radio items for settings that change the view, such as sorting.

## Keyboard

| Key | Action |
| --- | --- |
| Enter, Space, Arrow down | Open the menu and focus the first item |
| Arrow up, Arrow down | Move between items |
| Home, End | First or last item |
| Letters | Jump to the next item that starts with them |
| Escape | Close and return focus to the trigger |
