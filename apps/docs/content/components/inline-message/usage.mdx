---
title: Inline message usage
description: An inline message is a status icon that opens more detail in a small dialog.
---

## Usage

Inline messages point at one spot on the page, such as a field that failed to sync, without taking much room.

## Best practices

- Pair the icon with a short title so people know what it is about.
- Keep the dialog content short; link to more detail when needed.
- Don't use it for errors people must fix before continuing; show those on the page.
