## Usage

A modal dialog interrupts people to focus on one task or message. Everything behind it is inert until it closes, so use it only when the interruption is worth it.

## Accessibility

- Every modal needs a name: a `ModalTitle`, or a `label`.
- Focus moves into the modal and back to where it was when it closes. Tab stays inside the modal.
- Escape closes the modal unless `shouldCloseOnEscapePress` is false; offer another clear way out.
