## Install

```bash
pnpm add @interlink/react @interlink/css @interlink/tokens
```

## Use

Import the base stylesheet and the component styles once, at the root of your app.

```tsx
import '@interlink/css/interlink.css';
import '@interlink/react/styles.css';
```
